# MDFlow Screening Inputs

This folder contains the four protein-peptide complexes selected for the
10-ns molecular dynamics screening stage of the study.

## Input files

1. `Tsr-SLC6A6_P2.pdb`
2. `Tsr-SLC7A5_P1.pdb`
3. `Tar-SLC6A6_P2.pdb`
4. `Tar-COL1A1_P3.pdb`

## Important

- Do not modify these PDB files.
- Chain A corresponds to the receptor.
- Chain B corresponds to the peptide.
- Use the PDB files directly as MDFlow input.
- Do not manually edit the molecular structure or simulation parameters.

The four complexes are processed independently.
